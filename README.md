# react-course

React is a library for building user interfaces (java script based).

Example:

- Netflix page, all transitions are smooth, you click in a nav element and the whole page never reloads completely. Somehow it feels like a mobile page (smooth transitions between tabs, and app sections)


We will use js to update the page without reloading it, javascript can modify the page after loading


Why not using just vanilla js? Its an option but it easily becomes cumbersome (too much code and difficult to maintain) and error-prone


React offer a simpler mental model and porvides an easier way to create complex webs.


By default if you add html code in a js file it will raise an error. One of the main features of react is that you can blend js and html code

The example in section 1 works by creating a varible (activeContentIndex) and when a button is pressed, that changes. Then react will listen continously to that variable and "react" to its value. Changing html elements.


React is declarative UI programming --> You define the target UI state, not the steps to get there --> react automatically figures out the steps to create that

Vanila JS is imperative --> You do not define the goal, you define the steps to get there
